Mastering Pydantic

Pydantic is the most widely used data validation library for Python. It enforces type hints at runtime and provides robust error messages.

Level: Beginner

1. Basic Model & Type Validation

Define your data structure using BaseModel. Pydantic ensures that the types passed match the annotations, even performing smart coercion (e.g., string "1" to integer 1).

# Example usage:
user = User(id=1, username="jdoe", email="jdoe@example.com")
print(user)
>
Level: Intermediate

2. Field Constraints

Use the Field function to add metadata and strict validation rules like minimum length, maximum value, or numeric ranges.

# Example usage:
product = Product(name="Laptop", price=999.99, stock=10)
>
Level: Intermediate

3. Nested Models

Pydantic allows you to compose complex data structures by nesting one model inside another, creating a recursive validation tree.

# Example usage:
detailed = DetailedUser(user=user_obj, address=addr_obj, tags=["tech"])
>
Level: Advanced

4. Custom Validators

Implement complex logic using @field_validator for individual fields or @model_validator for multi-field dependencies.

# Example usage:
# Validates password complexity and ensures password == confirm_password
from pydantic import validator

class User(BaseModel):
    id: int
    username: str = Field(..., min_length=3, max_length=20)
    email: EmailStr
    age: int = Field(..., gt=18)
    
    @validator('password')
    def validate_password(cls, v, values, **kwargs):
        if len(v) < 8:
            raise ValueError("Password must be at least 8 characters long")
        return v
    
    @validator('confirm_password')
    def validate_confirm_password(cls, v, values, **kwargs):
        if 'password' not in values or v != values['password']:
            raise ValueError("Passwords do not match")
        return v
>
Level: Intermediate

5. Serialization & Configuration

Convert models back to Python dictionaries or JSON strings using model_dump() and model_dump_json().

# Example usage:
user = User(id=1, username="jdoe", email="jdoe@example.com")
print(user.model_dump())
print(user.model_dump_json(indent=4))
>

Real World Use Cases of Pydantic

Pydantic is used in various applications where data integrity and validation are crucial. Here are a few real-world examples:

Level: Advanced

API Validation

In web development, Pydantic can be used to validate incoming request data before processing it. This helps prevent invalid inputs and ensures that API endpoints only accept expected formats.

>
Level: Intermediate

Data Processing

In data processing pipelines, Pydantic can be used to ensure that data conforms to expected structures before performing transformations. This helps catch errors early in the pipeline and reduces the risk of downstream issues.

>
Level: Advanced

Data Validation in Business Logic

In enterprise applications, Pydantic can be used to validate data before it is processed by business logic. This helps ensure that the input data meets business rules and constraints.

>
Level: Intermediate

Data Transfer Objects (DTOs)

Pydantic can be used to define DTOs (Data Transfer Objects) that encapsulate data structures for use in communication between different parts of an application. This helps ensure consistency and reduces the risk of errors when passing data between components.
